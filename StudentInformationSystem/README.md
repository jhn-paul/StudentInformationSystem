# StudentHub – Student Information System

## System Description

StudentHub is a simple PHP-based Student Information System
designed to organize and display student records.

It allows users to view student information and search for
records using a name, student ID, course, year level, or email.

## Features

- Displays student records.
- Uses PHP arrays to store information.
- Uses PHP functions to process records.
- Searches student information.
- Counts total and active students.
- Uses PHP string functions.
- Displays information using HTML and CSS.
- Responsive dashboard design.

## Technologies Used

- PHP
- HTML
- CSS

## How to Run

1. Install XAMPP.
2. Start Apache.
3. Copy the project folder into htdocs.
4. Open your browser.
5. Visit:

http://localhost/StudentInformationSystem/
